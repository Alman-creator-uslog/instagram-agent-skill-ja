# Instagram エージェントスキル（日本語版）

インスタのアカウントを回す、Claude のスキル13個。無料・MIT ライセンス・登録なし・API キーなし・つなぐ物なし。

海外インフルエンサーが作成し話題になっていた [instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill)（作者 Jake Schincariol・MIT）を、日本語で使えるように作り直した物。手順書を日本語にしただけではなく、英単語を数えて点数を出していた計算の部分を、日本語の文字・読み・言い回しで測る作りに替えた（下の「日本語版で変えたこと」）。

1つは、ネタ1つからリールの台本を書く。フックの型26種類から3案を出し、撮る前に採点する。1つは、自分のジャンルで本当に伸びているリールを探しに行き、そのアカウントのふだんの再生数の何倍伸びたかで並べる。1つは、キャプションを書き、「…続きを読む」の前にフィードで何が見えるかをそのまま見せる。1つは、プロフィールを100点満点で採点して、点を落とした所を書き直す。1つは、1週間を計画する。

そして1つが「AIっぽさ消し」で、ほかのスキルが使い物になる理由。下書きから、AIの日本語に多い決まり文句・長いダッシュ・マークダウンの記号・見えない文字を消し、本人に見せる前に5項目で採点する。

**本人が「OK」と言うまで、何も投稿しない。** このスキルは書く。投稿するのは本人。

## 入れ方

Claude Code に、これを貼る:

```
https://github.com/Alman-creator-uslog/instagram-agent-skill-ja

このスキルを入れて、/ig-reel が動くか確かめて。
```

自分で入れるなら、Claude Code で（Mac・Linux）:

```bash
git clone https://github.com/Alman-creator-uslog/instagram-agent-skill-ja.git
mkdir -p ~/.claude/skills
cp -r instagram-agent-skill-ja/skills/ig-* ~/.claude/skills/
```

Windows（PowerShell）:

```powershell
git clone https://github.com/Alman-creator-uslog/instagram-agent-skill-ja.git
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude\skills" | Out-Null
Copy-Item -Recurse instagram-agent-skill-ja\skills\ig-* $env:USERPROFILE\.claude\skills\
```

プラグインとして入れるなら:

```
/plugin marketplace add Alman-creator-uslog/instagram-agent-skill-ja
/plugin install instagram-agent-ja
```

全体ではなく1つの作業フォルダだけで使うなら、同じフォルダを作業フォルダの `.claude/skills/` に写す。Claude Code を使わないなら、`SKILL.md` を1つ、チャットの最初に貼れば、そのモードとして動く。その場合は計算の道具（Python）が使えず、`/ig-reel` と `/ig-human` の大事な所が抜けるが、ほかは動く。

**英語版と一緒に入れない。** スキルの名前（/ig-reel など）が同じなので、どちらかだけにする。

道具は Python 3 で動く（追加で入れる物はない）。Windows で `python3` が無いと言われたら、`python` か `py` で動かす。

それから `templates/voice.md` に10分かける。`~/.claude/instagram/voice.md` に写して埋めるか、自分のリールを3本 Claude に渡して「これから voice.md を書いて」と言う。全部のスキルがこのファイルを読む。インスタではほかの所より大事。言葉を声に出して言うのは本人だから。

## 日本語版で変えたこと

| 場所 | 英語版 | 日本語版 |
| --- | --- | --- |
| 13個の手順書 | 英語 | 日本語に書き直し。例はドル→円、日本のインスタの言い方に |
| フックの型26種類 | 英語のひな形と、英語の言い回しを見分ける正規表現 | 日本語のひな形・記入例・テロップの形と、日本語の言い回しを見分ける正規表現 |
| フックの採点 | 英単語の数・英語の否定語・you の有無 | 読みの長さ（話す秒数）・日本語の「懸かっている言葉」・命令や「〜な人へ」の呼びかけ・漢数字と助数詞 |
| 秒割り表 | 1分に165語 | 読みの長さ（かなに直した音の数）÷ 1秒に話すかなの数。自分の速さを測る `--measured` を追加 |
| キャプションの検査 | 前から125文字で切る | 画面の幅（全角2・半角1）で2行に折り返して切る。全角の「＃」がハッシュタグにならないことも知らせる |
| AIっぽさの辞書 | delve・leverage など英語154語 | AIの日本語の決まり文句117個を一から作った（「することができ」「において」「いかがでしたか」など） |
| AIっぽさの判定 | 英単語の文の長さ・短縮形・人称 | 文字数の文の長さ（箇条書きは除く）・話し言葉の語尾・文末の種類・「〜ます」の連続 |
| 記号の直し | em dash・三点リーダー・矢印を直す | 長いダッシュとマークダウンを直す。三点リーダーと矢印は日本語でふつうなので触らない。絵文字の合成（家族の絵文字）を壊さない |
| 伸びたリールの並べ替え | 再生数は数字だけ | 「1.2万」「120万」「1.1億」「12K」「1.2M」を読む。列の名前は日本語でもいい |

## 本当に動く5つの道具

追加で入れる物なし、ネットにつながない、何も送信しない。自分の PC で、自分の文に対して動く。

### フック

```bash
python3 hookscore.py hooks.txt              # 案に順位をつける
python3 beats.py script.txt --target 30     # 撮る前に秒を測る
```

```
フックの順位
==============================================================================
->  71.8 強い     契約書の1行を抜かして、20万円を失いました。
        いちばん弱い: 相手に向く (55)
    65.4 まあまあ 誰も言わないけど、最初の30本のリールは伸びなくて当たり前。
        いちばん弱い: 長さ (50)
     7.8 弱い     ちょっと待って！インスタで伸びたい人は見て🔥
        いちばん弱い: 具体性 (15)
        致命的: 注目をお願いする出だし（「ちょっと待って」「最後まで見て」）。注目を頼むのは、まだ掴めていない証拠。
        致命的: フックに絵文字。フックの大きさのテロップに、言葉と絵文字の両方を置く場所はない。
     0.0 弱い     はいどうも、今日はコンテンツ戦略について話していきます
        いちばん弱い: 前に置く (0)
        致命的: 動画の前置き（「今日は〜を紹介します」）。消して、答えから始める。
        致命的: あいさつ。あいさつを聞きにフィードを見ている人はいない。
```

`beats.py` は、1行を言うのに何秒かかるかを見積もって時刻に積み上げ、編集でリールを殺す4つを知らせる。3秒を過ぎるフック、見ている人が離れるほど長い1カット、具体的な物のない行の連続、最初の行に戻るループがないこと。

```
秒割り表  ·  101字（読み約120音）  ·  約13.3秒（1秒に9かな）  ·  狙い20秒
========================================================================
  0:00.0   3.2秒  フック     契約書の1行を抜かして、20万円を失いました。
                             ^ フックが3.2秒。3秒を過ぎている
  0:03.2   3.0秒             これが、今は全部の契約書に入れている一文です。
  0:06.2   2.4秒  真ん中     「支払いは承認の時ではなく、納品の時」。
  0:08.6   1.8秒             承認は気持ち。納品は日付。
  0:10.5   2.8秒  締め       この一文だけで、20万円の価値がありました。
------------------------------------------------------------------------
  - 1行目を言うのに3.2秒かかる。約27字（読みの音の数）以内に削らないと、見るかどうか決まった後にフックが届く。
  - ループあり: 最後の行がフックの「20万円」をもう一度言っている。2回目の再生はタダのリーチ。
  - 狙いより6.7秒短い。約60字足すか、短いまま撮る。たいてい短いほうが正しい。
```

話す速さは人によって違う。台本を声に出して読んで秒数を測り、`beats.py script.txt --measured 42`のように入れると、自分の速さ（1秒に何かなか）が出る。次からはその数を `--cps` に入れる。

### キャプション

```bash
python3 caption.py caption.txt --keywords "契約書,フリーランス"
```

インスタはフィードでキャプションの最初の2行ほどだけを見せ、残りを「…続きを読む」の後ろに隠す。失敗するキャプションのほとんどは、そこで失敗している。日本語は1文字の幅が英字の約2倍で、行で切られるので、見えるのは全角30字ほどしかない。だからこの道具は最初に、流し見する人が読むままの形で、その部分を箱に入れて見せる。

```
  フィードで見える部分（1行目の頭はユーザーネーム）
  +------------------------------------------------+
  | ユーザーネーム 契約書の1行を抜かして、20万円を |
  | 失いました。しかも2回読んでからサ              |
  +--------------------------------- … 続きを読む +

  OK    長さ             164 / 2200字
  注意  1行目            43字あり、見える部分の途中で切れる。続きが気になる所で切れているなら良し、文の途中の説明で切れているなら悪い
  OK    具体性           見える部分に数字・名前が3個（1行, 20万円, 2回）
  OK    ハッシュタグ     3個: #フリーランス #契約書 #個人事業主
  OK    タグの位置       タグは「続きを読む」の後ろ
  OK    リンク           押せないリンクはない
  OK    お願いは1つ      お願いは1つ: コメント（合言葉）
  OK    絵文字           0個、100字あたり0.0個
  OK    検索される言葉   2/2個入っている、うち見える部分に1個
```

見える量は機種と文字の大きさで変わる。1回だけ自分のスマホで確かめて、`--width`（1行の幅）と`--lines`（行数）で合わせる。リールの画面のキャプションは1行ほどなので `--lines 1`。

今のハッシュタグの上限、**1投稿5個**で検査する。30個ではない。インスタが2025年12月18日に変えた。

### AIっぽさ消し

```bash
python3 humanize.py draft.txt --report      # 消して、変えた所を全部見せる
python3 detect.py draft.txt                  # 5項目で採点する
python3 detect.py before.txt after.txt       # 前後の差を見せる
```

**自動で消す物:**

- **見えない文字。** 幅ゼロの空白・つなぎ文字・ソフトハイフン・BOM・タグ文字・改行しない空白など。キーボードでは打てない。コピーしても残り、どのエディタでも見えない。全角の空白と、絵文字の合成に使う文字は残す。
- **記号。** 長いダッシュ→「、」（文の終わりの後なら「。」）、数字の間の短いダッシュ→「〜」、英語のかぎ→「」、マークダウンの太字と見出しの記号を消す。
- **決まり文句。** AIの日本語に多い言い回し117個を、ふつうの言い方に。最後の塊はインスタ特有の物（「スクロールしないで」「この動画では、」「最後まで見てね」「いいねとフォローお願いします」）。[`slop.json`](skills/ig-human/slop.json) にあり、自分で直す前提。

**直さずに知らせる物:** 「〜だけでなく、〜も」、3つ並べ、1行だけの問いかけ、動画の前置き、「〜ではないでしょうか」、文末が同じ形で3回以上続くこと、文の長さのそろいすぎ、絵文字の箇条書き、ハッシュタグの壁、反射の「フォローしてね」。文の形を変えるには判断が要るので、正規表現で壊さず、書き直す所として返す。

わざとAIっぽく書いたキャプションに通すと:

```
  文のばらつき  #################.......  69.1
  具体性        #############...........  52.6
  決まり文句    ........................   0.0    17個、100字あたり7.1個
  記号の跡      ........................   0.0    長いダッシュ1・マークダウン1
  話し手の声    ####....................  16.7    文末の種類44%、文の形の跡3個
  --------------------------------------------------------------
  人らしさ      ####....................  16.6   AIっぽい
```

`humanize.py` の後（知らせた文の形はまだ書き直していない状態）:

```
  人らしさ      ##########..............  43.6   AIっぽい   (+27.0)
```

残りは、知らせた「3つ並べ」と「〜ます。」の連続を、自分で書き直す分。

## 日本語版で測ったこと

英語版の作者は、点数の道具を「それっぽい」で出さずに試験していた（下の節）。日本語版でも、作り直した部分を日本語の実データで試した。

**1. 読みの長さの見積もり。** 日本語のリール台本8本で、実際の読み（かなに直した音の数）と比べた。漢字1字の読みは中央値で1.7音で、見積もりの誤差は2%以内。カット編集を終えたリールの話す速さは中央値で1秒に約10かな。撮る前の素の速さの初期値は1秒に9かなにした。

**2. フックの採点は、下手なフックを見分ける。** Threads と X で伸びた日本語の投稿の1行目2,005本と、わざと下手に書いた日本語のフック20本（あいさつ・前置き・「ちょっと待って」など）で比べて、AUC 0.91（0.5がコイン投げ、1.0が完全）。下手な20本のうち19本が、本物の中央値より下だった。英語版の結果（AUC 0.83）とほぼ同じ。

**3. 当たりと外れは見分けない。** 同じジャンルの中で、いいねの上位4分の1と下位4分の1を比べると AUC 0.47。コイン投げと変わらない。英語版（0.56）と同じ結論で、使い方も同じ。明らかに弱いフックを撮る前に落とし、そこから先は自分の視聴維持のグラフを信じる。まあまあのフック2つのどちらが伸びるかは、顔・編集・音・インスタが誰に見せるかで決まり、文字からは分からない。

**4. 型の名前が付くのは一部だけ。** 26の型の記入例は26本とも正しい型に当たる。伸びた投稿の1行目2,014本では、型の名前が付いたのは14%。英語版は話したフックで49%だった。日本語版の試験はThreads と X の文の1行目で、リールの話したフックではないので、そのまま比べられない。名前が付かない物は、雑音か、まだ `hooks.json` にない型。`/ig-viral` の手順4で手で読む。

**5. AIっぽさの判定。** 人が書いて伸びた日本語の投稿200本の「人らしさ」の中央値は73点。AIの定番の書き方で書いた12本は、12本とも「AIっぽい」と出た（見分ける力は AUC 0.99）。ただし、人の投稿の約1割も「AIっぽい」と出る。数字のない意見の投稿や、「です・ます」だけの投稿が低く出やすい。点数は目安で、最後は本人が読む。

**正直な限界:** 試験に使った「本物」は Threads と X の投稿で、インスタのリールではない。インスタは、人のアカウントにログインせずに再生数を集める方法がなく、集めればこのスキル集が破るなと言っている利用規約に反するから。AIっぽい側の12本も、AIの定番の書き方をまねて書いた物で、実際のAIの出力を大量に集めた物ではない。もっと大きく正確なデータで違う答えが出たら、知らせてほしい。

## 英語版で測ったこと（元の作者の試験）

元の作者は、YouTube ショートの上位と下位のフック74本で試していた（インスタは再生数を規約の範囲で集められないため）。わざと下手に書いたフックの見分けは AUC 0.83、同じ人の当たりと外れの見分けは AUC 0.56。5項目のうち差が出たのは具体性だけだった。型の見分けは、最初は自分のひな形から書いた正規表現で8%しか名前が付かず、実際の話し言葉に合わせて書き直して49%にした。その時に「常識の逆」「統計の数字」「お披露目」「他人の結果」「一番〜」の型が足された。数字を数字でしか数えず「ゼロドル」を具体的と見なかった不具合も、この試験で見つかって直った。

## 注意書き（いちばん正直な所）

**このスキルはインスタに投稿しない。** プロアカウント向けの正式な投稿の仕組み（Content Publishing API）はあるが、Meta の開発者アプリ・長期のトークン・アプリの審査が要り、スキルが渡せる物ではない。投稿・コメント・フォロー・DM を自動にするほかの方法は、ブラウザの自動操作か外部のツールで、どちらもインスタの[利用規約](https://help.instagram.com/581066165581870)に反し、操作制限がかかる。だからどのスキルも最後は同じ。そのまま貼れる文を出し、本人が投稿する。後から付けた制限ではなく最初からの作りで、承認の関門が設定ではなく本物である理由。

例外は、DM の合言葉への自動返信。インスタ自身の機能と、公式に認められた連携ツールでできて、相手がコメントした後にだけ動く。`/ig-dm` に、その線がどこかを書いてある。

**`/ig-viral` は読むだけで、機械的に集めない。** 10アカウント・1つにつき12本くらいを、人の速さで、本人が自分のブラウザを動かして。パスワードを聞かないし、本人としてログインしない。大量の自動収集こそがアカウントの制限につながる物で、これはそれではない。

**5つの判定は手元の目安で、判定サービスではない。** 公開されている判定の道具が見ている合図をまねて作り、全部が本人の PC の中で動く。GPTZero・Originality・Copyleaks・Winston・Turnitinではなく、それらに問い合わせず、その判定を約束できない。ここで測る物を直すと向こうの数字も動きやすい。同じ物を測っているから。言えるのはそこまで。「ばれない」を売る人は、何か別の物を売っている。

**見えない文字の消去は本物で、範囲は狭い。** 生成された文に入り、コピーしても残る、幅ゼロの文字と書式の文字を消す。確かめられる本物の跡。暗号を使った電子透かしを破るという話ではないし、このスキル集はそう言わない。

**ここでは何もでっちあげない。** 本人の名前で、作った数字・顧客・結果を出さない。もらっていない数字が要る下書きは、毎回 `{{あなたの数字}}` を入れて、知らせて返す。

**仕様の数字は古くなる。** ハッシュタグの上限は、英語版を作っている途中の2025年12月に30から5に変わった。読んだ時にここの何かがインスタの今のやり方と違ったら、インスタが正しい。キャプションの見える量も機種で変わる。
