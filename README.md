# Instagram エージェントスキル（日本語版）

インスタ運用を Claude に任せるための、Claude Code 用スキル13個のセットです。無料・MIT ライセンスで、会員登録も API キーも、外部サービスとの連携もいりません。

海外インフルエンサーが作成し話題になっていた [instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill)（作者 Jake Schincariol・MIT）を、日本語で使えるように作り直しました。手順書を訳しただけではありません。英語版は英単語を数えて点数を出していたので、その計算の部分を、日本語の文字数・読み・言い回しで測る仕組みに入れ替えています（詳しくは「日本語版で変えたこと」）。

たとえば、こんなことができます。

- ネタを1つ渡すと、リールの台本を書きます。26種類のフックの型から3案を出し、撮る前に採点します。
- 自分のジャンルで本当に伸びているリールを探し、そのアカウントのふだんの再生数の何倍伸びたかで並べます。
- キャプションを書き、フィードで「…続きを読む」の前にどこまで見えるかを、そのままの形で見せます。
- プロフィールを100点満点で採点し、点を落とした所を書き直します。
- 1週間の投稿計画を立てます。

そして、ほかのスキルを実用レベルに引き上げているのが「AIっぽさ消し」です。下書きから、AIが書く日本語にありがちな決まり文句や、長いダッシュ、マークダウンの記号（`**` や `#` など、太字や見出しを付ける記号）、目に見えない文字を取り除き、あなたに見せる前に5つの項目で採点します。

**あなたが「OK」と言うまで、何も投稿しません。** スキルが書くのは下書きまでで、投稿するのはあなたです。

## 入れ方

Claude Code に、次の文をそのまま貼ってください。

```
https://github.com/Alman-creator-uslog/instagram-agent-skill-ja

このスキルを入れて、/ig-reel が動くか確かめて。
```

自分でコマンドを打って入れる場合（Mac・Linux）:

```bash
git clone https://github.com/Alman-creator-uslog/instagram-agent-skill-ja.git
mkdir -p ~/.claude/skills
cp -r instagram-agent-skill-ja/skills/ig-* ~/.claude/skills/
```

Windows（PowerShell）の場合:

```powershell
git clone https://github.com/Alman-creator-uslog/instagram-agent-skill-ja.git
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude\skills" | Out-Null
Copy-Item -Recurse instagram-agent-skill-ja\skills\ig-* $env:USERPROFILE\.claude\skills\
```

プラグインとして入れる場合:

```
/plugin marketplace add Alman-creator-uslog/instagram-agent-skill-ja
/plugin install instagram-agent-ja
```

特定の作業フォルダだけで使いたい場合は、`skills/` の中の `ig-` で始まるフォルダを、その作業フォルダの `.claude/skills/` にコピーしてください。Claude Code 以外のチャットで使う場合は、`SKILL.md` を1つチャットの最初に貼れば、そのスキルとして動きます。ただしその場合は計算用のツール（Python）が使えないため、`/ig-reel` と `/ig-human` は大事な部分が欠けます。ほかのスキルはそのまま使えます。

**英語版と一緒には入れないでください。** スキルの名前（/ig-reel など）が同じなので、どちらか一方だけにします。

ツールを動かすには Python 3（プログラムを動かすためのソフト）が必要です。それ以外に入れるものはありません。Windows で「`python3` が見つからない」と出た場合は、`python` か `py` に置き換えて実行してください。

入れたら、まず `templates/voice.md`（話し方の設定）を10分ほどかけて埋めてください。`~/.claude/instagram/voice.md` にコピーして自分で書くか、自分のリールを3本 Claude に渡して「これを元に voice.md を書いて」と頼めば作れます。すべてのスキルがこのファイルを読みます。この設定は、文章だけの SNS よりもインスタで特に大事です。台本を声に出して話すのは、あなた自身だからです。

## 13個のスキル

| コマンド | できること |
| --- | --- |
| `/ig-reel` | ネタ1つからリールを作ります。[26種類の型](skills/ig-reel/hooks.json)からフックを3案出して採点し、台本・テロップ・秒割り表まで書きます。 |
| `/ig-viral` | 自分のジャンルで伸びている投稿を探し、各アカウントのふだんの再生数（中央値）の何倍伸びたかで並べます。フックの型を見分けて、伸びた型をメモにまとめます。 |
| `/ig-caption` | キャプションを書いて検査します。フィードで「…続きを読む」の前に見える部分を、そのままの形で確認できます。 |
| `/ig-carousel` | カルーセルを作ります。スワイプしたくなる表紙、1枚ずつの文面、1080×1350 の画像まで作ります。 |
| `/ig-story` | 毎日のストーリーズの流れを作ります。どのスタンプを何に使うか、相手から話しかけてもらう形で DM につなげる流れも含みます。 |
| `/ig-profile` | プロフィールを[12項目の採点表](skills/ig-profile/rubric.json)で100点満点で採点し、直す順番に書き直します。 |
| `/ig-plan` | 1週間の計画を立てます。何を、どの形式で、いつ出すか。交流する10アカウントも決めます。 |
| `/ig-human` | AIっぽさ消しです。文章を自動で直すツールと、採点するツールの2つが入っています（下で説明します）。 |
| `/ig-comment` | 他の人の投稿へのコメントを書きます。9つの型から、投稿の内容に合うものを選びます。「🔥🔥🔥」のようなコメントは書きません。 |
| `/ig-reply` | 自分の投稿についたコメントへの返信を書きます。合言葉・見込み客・中身のある感想・質問・応援・相手にしなくていいもの、に分けて、この順に返します。 |
| `/ig-dm` | DM を書きます。合言葉をくれた人への特典の送付、最初のメッセージ、コラボの提案、追いメッセージ（2回まで）。 |
| `/ig-repurpose` | 動画・ポッドキャスト・メルマガ1本を、それぞれ単体で成り立つ1週間分のリールとカルーセルに作り直します。 |
| `/ig-audit` | 出した投稿を振り返ります。再生数ではなく、伸び倍率とリーチあたりのシェア数で並べます。 |

## 日本語版で変えたこと

| 場所 | 英語版 | 日本語版 |
| --- | --- | --- |
| 13個の手順書 | 英語 | 日本語に書き直しました。例の金額はドルから円に、言い回しは日本のインスタに合わせています |
| フックの型（26種類） | 英語のひな形と、英語の言い回しを見分けるルール | 日本語のひな形・記入例・テロップの形と、日本語の言い回しを見分けるルール |
| フックの採点 | 英単語の数、英語の否定語、「you」が入っているか | 読みの長さ（話すのにかかる秒数）、「損」「失敗」のように見ないと損をしそうだと感じさせる言葉、命令や「〜な人へ」などの呼びかけ、漢数字と「本」「円」などの数え方の言葉 |
| 秒割り表 | 1分に165語として計算 | 読みの長さ（かなに直した音の数）÷ 1秒に話すかなの数で計算。自分の話す速さを測る `--measured` を追加 |
| キャプションの検査 | 先頭から125文字で切る | 画面の幅（全角は2・半角は1と数える）で2行に折り返して切ります。全角の「＃」がハッシュタグにならないことも知らせます |
| AIっぽさの辞書 | 「delve」「leverage」など英語154語 | AIが書く日本語の決まり文句117個を新しく作りました（「することができ」「において」「いかがでしたか」など） |
| AIっぽさの判定 | 英単語で数えた文の長さ、短縮形、人称 | 文字数で数えた文の長さ（箇条書きは除く）、話し言葉の語尾、文末の種類、「〜ます」の連続 |
| 記号の修正 | 長いダッシュ・三点リーダー・矢印を直す | 長いダッシュとマークダウンの記号を直します。三点リーダーと矢印は日本語ではふつうに使うので残します。家族の絵文字のような組み合わせの絵文字も壊しません |
| 伸びたリールの並べ替え | 再生数は数字だけ | 「1.2万」「120万」「1.1億」「12K」「1.2M」といった書き方も読めます。列の名前も日本語で書けます |

## 付属の5つのツール

追加で入れるものはなく、ネットにもつながらず、何も外に送りません。あなたの文章を、PC の中だけで測ります。

### フック

```bash
python3 hookscore.py hooks.txt              # 案に順位をつける
python3 beats.py script.txt --target 30     # 撮る前に秒を測る
```

```
フックの順位
==============================================================================
->  71.8 強い     契約書の1行を抜かして、20万円を失いました。
        いちばん弱い: 相手に向く (55)
    65.4 まあまあ 誰も言わないけど、最初の30本のリールは伸びなくて当たり前。
        いちばん弱い: 長さ (50)
     7.8 弱い     ちょっと待って！インスタで伸びたい人は見て🔥
        いちばん弱い: 具体性 (15)
        致命的: 注目をお願いする出だし（「ちょっと待って」「最後まで見て」）。注目を頼むのは、まだ掴めていない証拠。
        致命的: フックに絵文字。フックの大きさのテロップに、言葉と絵文字の両方を置く場所はない。
     0.0 弱い     はいどうも、今日はコンテンツ戦略について話していきます
        いちばん弱い: 前に置く (0)
        致命的: 動画の前置き（「今日は〜を紹介します」）。消して、答えから始める。
        致命的: あいさつ。あいさつを聞きにフィードを見ている人はいない。
```

`beats.py` は、1行ずつ話すのにかかる秒数を見積もって各行が何秒目に始まるかを出し、編集でリールを台無しにしがちな4つの点を知らせます。3秒を超えるフック、見ている人が離れるほど長い1カット、具体的な中身のない行の連続、最後に1行目へ戻る「ループ」がないこと、の4つです。

```
秒割り表  ·  101字（読み約120音）  ·  約13.3秒（1秒に9かな）  ·  狙い20秒
========================================================================
  0:00.0   3.2秒  フック     契約書の1行を抜かして、20万円を失いました。
                             ^ フックが3.2秒。3秒を過ぎている
  0:03.2   3.0秒             これが、今は全部の契約書に入れている一文です。
  0:06.2   2.4秒  真ん中     「支払いは承認の時ではなく、納品の時」。
  0:08.6   1.8秒             承認は気持ち。納品は日付。
  0:10.5   2.8秒  締め       この一文だけで、20万円の価値がありました。
------------------------------------------------------------------------
  - 1行目を言うのに3.2秒かかる。約27字（読みの音の数）以内に削らないと、見るかどうか決まった後にフックが届く。
  - ループあり: 最後の行がフックの「20万円」をもう一度言っている。2回目の再生はタダのリーチ。
  - 狙いより6.7秒短い。約60字足すか、短いまま撮る。たいてい短いほうが正しい。
```

話す速さは人によって違います。台本を声に出して読んで秒数を測り、`beats.py script.txt --measured 42`（42秒だった場合）のように入れると、あなたの話す速さ（1秒に話すかなの数）が出ます。次からはその数字を `--cps` に入れてください。

### キャプション

```bash
python3 caption.py caption.txt --keywords "契約書,フリーランス"
```

インスタのフィードでは、キャプションは最初の2行ほどしか表示されず、残りは「…続きを読む」の後ろに隠れます。うまくいかないキャプションのほとんどは、ここでつまずいています。日本語は1文字の幅が英字の約2倍あり、行単位で切られるので、見えるのは全角30字ほどしかありません。そこでこのツールは、流し見している人に見えるのと同じ形で、その部分を枠で囲んで見せます。

```
  フィードで見える部分（1行目の頭はユーザーネーム）
  +------------------------------------------------+
  | ユーザーネーム 契約書の1行を抜かして、20万円を |
  | 失いました。しかも2回読んでからサ              |
  +--------------------------------- … 続きを読む +

  OK    長さ             164 / 2200字
  注意  1行目            43字あり、見える部分の途中で切れる。続きが気になる所で切れているなら良し、文の途中の説明で切れているなら悪い
  OK    具体性           見える部分に数字・名前が3個（1行, 20万円, 2回）
  OK    ハッシュタグ     3個: #フリーランス #契約書 #個人事業主
  OK    タグの位置       タグは「続きを読む」の後ろ
  OK    リンク           押せないリンクはない
  OK    お願いは1つ      お願いは1つ: コメント（合言葉）
  OK    絵文字           0個、100字あたり0.0個
  OK    検索される言葉   2/2個入っている、うち見える部分に1個
```

見える量は、機種や文字の大きさで変わります。一度だけ自分のスマホで確かめて、`--width`（1行の幅）と `--lines`（行数）で合わせてください。リール画面のキャプションは1行ほどしか出ないので、`--lines 1` にします。

ハッシュタグは、今の上限の**1投稿5個**で検査します（30個ではありません）。インスタが2025年12月18日に変更しました。

### AIっぽさ消し

```bash
python3 humanize.py draft.txt --report      # 消して、変えた所を全部見せる
python3 detect.py draft.txt                  # 5項目で採点する
python3 detect.py before.txt after.txt       # 前後の差を見せる
```

**自動で消すもの:**

- **目に見えない文字。** 幅ゼロのスペース、つなぎ文字、ソフトハイフン、BOM、タグ文字、改行しないスペースなど。キーボードでは打てず、コピーしても残り、どのエディタでも見えません。ただし、全角スペースと、組み合わせの絵文字に使う文字は残します。
- **記号。** 長いダッシュは「、」に（文の終わりの直後なら「。」に）、数字の間の短いダッシュは「〜」に、英語の引用符は「」に置き換えます。マークダウンの太字や見出しの記号は消します。
- **決まり文句。** AIの日本語にありがちな言い回し117個を、ふつうの言い方に置き換えます。そのうち一部はインスタ特有のもの（「スクロールしないで」「この動画では、」「最後まで見てね」「いいねとフォローお願いします」）です。辞書は [`slop.json`](skills/ig-human/slop.json) にあり、自分で書き足して使う前提です。

**自動では直さず、知らせるもの:** 「〜だけでなく、〜も」、3つ並べ、1行だけの問いかけ、動画の前置き、「〜ではないでしょうか」、同じ文末が3回以上続く、文の長さがそろいすぎている、絵文字の箇条書き、ハッシュタグの羅列、とりあえずの「フォローしてね」。文の形を変えるには判断が必要なので、機械的に書き換えて壊すことはせず、書き直す箇所として返します。

わざとAIっぽく書いたキャプションを通すと、こうなります。

```
  文のばらつき  #################.......  69.1
  具体性        #############...........  52.6
  決まり文句    ........................   0.0    17個、100字あたり7.1個
  記号の跡      ........................   0.0    長いダッシュ1・マークダウン1
  話し手の声    ####....................  16.7    文末の種類44%、文の形の跡3個
  --------------------------------------------------------------
  人らしさ      ####....................  16.6   AIっぽい
```

`humanize.py` を通した後（知らせた文の形は、まだ書き直していない状態）:

```
  人らしさ      ##########..............  43.6   AIっぽい   (+27.0)
```

ここから先は、知らせた「3つ並べ」と「〜ます。」の連続を、あなたが書き直して点を上げる部分です。

### 伸びた型のメモ

```bash
python3 swipe.py captured.tsv --out ~/.claude/instagram/swipe.md
```

再生数そのものは、伸びた証拠になりません。フォロワー200万人のアカウントで40万回なら、そのアカウントにとってはむしろ伸びなかった日です。フォロワー4,000人のアカウントで40万回なら、何かが当たっています。`swipe.py` は、各アカウントのふだんの再生数（中央値）の何倍伸びたかで並べ、フックの型を見分け、上位3分の1と下位3分の1の違いを出します。

## 日本語版で検証したこと

英語版の作者は、点数を出すツールを「それらしく見える」だけで終わらせず、データで検証していました（下の節）。日本語版でも、作り直した部分を日本語の実際のデータで検証しました。

数字の読み方: 「見分ける力」は AUC という指標です。0.5 ならでたらめに当てるのと同じ、1.0 なら完璧です。

**1. 読みの長さの見積もり。** 日本語のリール台本8本で、ツールの見積もりと実際の読み（かなに直した音の数）を比べました。漢字1字の読みは中央値で1.7音、見積もりの誤差は2%以内でした。カット編集を終えたリールの話す速さは、中央値で1秒に約10かなです。カットで間を詰める前の、ふだん話す速さに合わせて、初期値は1秒に9かなにしています。

**2. フックの採点は、下手なフックを見分けられる。** Threads と X で伸びた日本語の投稿の1行目2,005本と、わざと下手に書いた日本語のフック20本（あいさつ・前置き・「ちょっと待って」など）を比べると、見分ける力は 0.91 でした。下手な20本のうち19本が、伸びた投稿の中央値より低い点でした。英語版（0.83）と同じく、下手なフックをよく見分けられています。

**3. 当たりと外れまでは見分けられない。** 同じジャンルの中で、いいね数の上位4分の1と下位4分の1を比べると、見分ける力は 0.47 で、でたらめと変わりません。英語版（0.56）と同じ結論なので、使い方も同じです。明らかに弱いフックは撮る前に落とし、そこから先は自分の視聴維持率のグラフを信じてください。まあまあのフック2つのどちらが伸びるかは、顔・編集・音、そしてインスタが誰に見せるかで決まり、文字だけでは分かりません。

**4. 型の名前が付くのは一部だけ。** 26種類の型の記入例は、26本とも正しい型に判定されます。一方で、伸びた投稿の1行目2,014本のうち、型の名前が付いたのは14%でした（英語版は、話したフックで49%）。ただし日本語版の検証は Threads と X の投稿の1行目で、リールで話したフックではないので、単純には比べられません。型の名前が付かないものは、型に当てはまらないフックか、まだ `hooks.json` に入っていない型です。`/ig-viral` の手順4で、人の目で読みます。

**5. AIっぽさの判定。** 人が書いて伸びた日本語の投稿200本では、「人らしさ」の中央値は73点でした。AIによくある書き方で作った12本は、12本とも「AIっぽい」と判定されました（見分ける力は 0.99）。ただし、人が書いた投稿の約1割も「AIっぽい」と出ます。数字のない意見の投稿や、「です・ます」だけの投稿は低く出やすいです。点数はあくまで目安で、最後はあなた自身が読んで判断してください。

**検証の限界:** 検証に使った「伸びた投稿」は Threads と X のもので、インスタのリールではありません。インスタでは、ログインせずに他人の再生数を集める方法がなく、集めようとすると、このスキルが守っている利用規約に反するためです。AIっぽい側の12本も、AIによくある書き方をまねて作ったもので、実際のAIの出力を大量に集めたものではありません。もっと大きく正確なデータで違う結果が出たら、ぜひ教えてください。

## 英語版で検証したこと（元の作者の検証）

元の作者は、YouTube ショートの上位と下位のフック74本で検証していました（インスタの再生数は、規約の範囲内では集められないため）。わざと下手に書いたフックを見分ける力は 0.83、同じ人の当たりと外れを見分ける力は 0.56 です。5つの項目のうち、差が出たのは具体性だけでした。型の見分けは、最初は自作のひな形から作ったルールで8%しか名前が付かず、実際の話し言葉に合わせて作り直して49%まで上げています。このとき「常識の逆」「統計の数字」「お披露目」「他人の結果」「一番〜」の型が追加されました。具体性の採点が「0」のような算用数字しか数えず、「ゼロドル」のように言葉で書いた数字を具体的と判定できなかった不具合も、この検証で見つかって直っています。

## 注意事項

**このスキルはインスタに投稿しません。** プロアカウント向けの正式な投稿の仕組み（Content Publishing API）はありますが、Meta への開発者登録とアプリの作成、長く使える認証用のキー（アクセストークン）、アプリの審査が必要で、スキルとして配れるものではありません。投稿・コメント・フォロー・DM を自動化するほかの方法は、ブラウザの自動操作か外部ツールで、どちらもインスタの[利用規約](https://help.instagram.com/581066165581870)に反し、アカウントに操作制限がかかります。だから、どのスキルも最後は同じです。そのまま貼れる文章を出し、投稿はあなたがします。これは後から付けた制限ではなく、最初からの設計です。だから、あなたの OK なしに投稿されることは、どんな設定でも起きません。

例外は、合言葉をコメントした人へ DM を自動で送る仕組みです。インスタ自身の機能や、公式に認められた連携ツールで使えて、相手がコメントした後にだけ動きます。どこまでが大丈夫かは `/ig-dm` に書いてあります。

**`/ig-viral` は見て読むだけで、機械的な収集はしません。** 10アカウント、1アカウントにつき12本ほどを、人と同じペースで、あなた自身のブラウザで見ていきます。パスワードを聞いたり、あなたになりすましてログインしたりはしません。アカウント制限の原因になるのは大量の自動収集で、これはそれとは違います。

**5つの判定は手元の目安で、AI判定サービスではありません。** 公開されているAI判定ツールが見ているポイントをまねて作ったもので、すべてあなたの PC の中で動きます。GPTZero・Originality・Copyleaks・Winston・Turnitin とは別物で、それらに問い合わせることもなく、その判定結果を保証するものでもありません。ここで測るポイントを直すと、それらのツールの数字も動きやすくなります。同じところを見ているからです。言えるのはそこまでです。「絶対にAIだとばれない」とうたう話は、信用しないでください。

**見えない文字の削除は実際に効きますが、範囲は限られます。** 生成された文に入り込み、コピーしても残る、幅ゼロの文字や書式用の文字を消します。これは実際に確かめられる痕跡です。暗号を使った電子透かしを破るという話ではありませんし、このスキルもそうは言いません。

**数字や実績をでっち上げません。** あなたの名前で、架空の数字・お客さん・成果を出すことはしません。あなたから聞いていない数字が必要な下書きには、必ず `{{あなたの数字}}` を入れて、そのことを伝えて返します。

**仕様の数字は古くなります。** ハッシュタグの上限は、英語版の制作中だった2025年12月に30個から5個に変わりました。ここに書いてあることが今のインスタと違っていたら、インスタのほうが正しいです。キャプションの見える量も、機種によって変わります。
